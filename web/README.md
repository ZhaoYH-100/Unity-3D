# Unity Inspection Web

React + TypeScript + Vite management UI for the Unity 3D inspection exercise.

```powershell
npm ci
npm run dev
```

The default backend address is `http://127.0.0.1:8080`. Override it with
`VITE_API_BASE_URL`.

```powershell
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```
